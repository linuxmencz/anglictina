# Angličtina pro Čechy

Jednoduchá webová aplikace na učení britské angličtiny pro české mluvčí (úroveň A1) s namluvenými slovíčky.
Jen pro osobní a nekomerční použití mezi známými.

- 10 lekcí po 12 slovech, opakování, statistiky
- Procvičování: typické chyby Čechů, falešní přátelé, minimální páry, skládání vět, přiřazování dvojic
- Postup se ukládá v prohlížeči; v aplikaci je možné stáhnout zálohu do souboru

Hlasy: [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (Apache 2.0).
